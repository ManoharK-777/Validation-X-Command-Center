# JARVIS V7 | Tactical Intelligence Command Center

A cinematic, Jarvis-inspired AI Validation Command Center built with **Node.js**, **Express**, and **EJS**.

## 🚀 Features

- **JARVIS V7 HUD** — Neo-Tactical dark UI with glassmorphism & animated holographic elements
- **3D Rotating Globe** — Full wireframe holographic globe widget
- **DNA Helix Animation** — Bio-scan matrix with animated DNA sequence
- **Dual Core-Sync Circles** — Concentric rotating rings for neural processing display
- **Form Validation** — Server-side validation with animated success transitions
- **Email Notifications** — Tactical mission briefing sent to inbox on every submission (via Nodemailer + Gmail)
- **Mission Secured Page** — Red-stamp "ACCEPTED" confirmation with decrypted mission log display
- **Precision Cursor** — Blue tactical plus (+) crosshair cursor

## 🛠️ Tech Stack

- **Backend**: Node.js, Express.js
- **Templating**: EJS
- **Email**: Nodemailer (Gmail SMTP)
- **Styling**: Vanilla CSS (Custom HUD Design System)
- **Fonts**: Orbitron, JetBrains Mono (Google Fonts)

## ⚙️ Setup & Run

```bash
npm install
npm start
```

Server runs at `http://localhost:3000`

## 🌐 Deployment

- **Backend**: Render (Node.js Web Service)
- **CDN/Domain**: Cloudflare
